# Backlog Ideas (Parking Lot)

All spontaneous feature ideas, UI animations, and architecture changes discovered during implementation
or review land here. They are NEVER pulled into the active sprint automatically.

A human must explicitly create a TICKET.md entry to promote any item from here.

---

## Format

Each entry: one sentence + date + source surface.

`[DATE] [SURFACE] — one-sentence idea`
