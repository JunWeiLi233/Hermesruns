# Deploy 2026-08-28 — Heatmap & Runs performance release

Draft PR used as the deploy gate for the changes already on `master`.
Merge after repointing the Railway service to the `master` branch
(Railway previously watched `codex/signup-recaptcha-railway-20260827`,
which was deleted during branch consolidation, so pushes stopped deploying).

## Shipping in this release

1. **Heatmap bounds + sampled render pool** — trimmed-sample bounds stop stray
   GPS points pinning the map at world zoom; `?sample=true` returns one
   bounded 25k-point pool (was 18 requests / ~75MB for 1.7M points).
2. **Same-origin basemap tiles** — Esri Dark Gray served through
   `/api/maps/tiles/esri-dark[-labels]/{z}/{y}/{x}.png`; visitor networks that
   cannot reach arcgisonline.com get a map instead of a black canvas.
   CARTO tiles remain available via the keyed proxy endpoint.
3. **Runs list virtualization** — scroll-driven 60-card batches (the 120ms
   background force-mount timer that rendered all 7.4k cards is gone) plus
   `content-visibility` on offscreen cards.
4. **Run detail data flow** — `/api/activities?id=` serves one feed item;
   `?limit=` serves the recent-run window; the detail load effect keys on
   `run?.id` so identity refreshes no longer re-fetch the endpoint quartet.
5. **Page-speed work** — Material Symbols font moved out of the gated app.css
   (admin loads it on demand), app.css fetch starts at module evaluation,
   Google Fonts preconnects removed, SVG compressed at the origin.
6. **Hygiene (this PR)** — redacted local username paths and a Discord
   channel id from docs/scripts; `%USERPROFILE%` replaces a hardcoded path.
