Hermes API System — Request Lifecycle

One /api request from React apiFetch through the servlet filters and Spring Security tiers to controllers, services, and stores.

Token Boundary

  • apiFetch attaches Bearer hermes_jwt plus Accept-Language on every /api call.
  • A 401 clears the hermes_* localStorage keys and redirects to /login.
  • Sessions are STATELESS and CSRF stays off because auth is header-token based.

Filter Order

  • Rate limits guard /api first (webhook paths exempt), then security headers, then the session-token filter.
  • SecurityConfig matchers route each request into the public, admin, or runner tier.
  • Admin surfaces need ROLE_ADMIN plus the short-lived portal cookie for /dashboard documents.

Downstream Plane

  • REST controllers under /api delegate to domain services.
  • JPA repositories persist domain entities on H2 (dev) or PostgreSQL (production).
  • Webhook entry points retain their provider-specific validation and rate limits.
